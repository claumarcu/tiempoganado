# Parking

Espacio para registrar ideas, decisiones o funcionalidades que aparecen durante el diseño del proyecto pero que pertenecen a documentos o etapas posteriores.

## Pendientes
Estados comerciales de una conversación.
Interpretación de respuestas.
Reglas de seguimiento.
Plazos de seguimiento.
Posible interpretación automática de respuestas mediante IA.
Detección de situaciones como "lo voy a pensar", "pedime información", etc.

- Campaña para actualizar preferencias de los contactos.
- Posibilidad de que cada contacto indique qué información quiere recibir.
- Posibilidad de registrar intereses como edición, autoral, presencial, online, etc.
- Posibilidad de confirmar o actualizar ubicación/modalidad.
- Actualización automática de estos datos a partir de las respuestas.
